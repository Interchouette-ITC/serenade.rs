DOCUMENTATION · FIRST STEPS

Get to know{{ space }}Serenade.

Serenade is pre-1.0. Start with the core bundle demo, then explore four runnable front-end modes: server-rendered HTML, a client-rendered SPA, static-site generation, and a Universal app with a live backend.

1. Install the prerequisites

Install Rust 1.99.0 or newer, GNU Make, Trunk, and the WebAssembly target. The first Cargo build downloads dependencies. 

{{ setupCommands }}

2. Run the tests and core demo

Run the workspace tests, then start the small bundle sample. The demo prints registered bundles, a greeting, event subscribers, and routes, then exits. 

{{ coreCommands }}

To try the interactive console instead, run{{ space }}make console ARGS='serenade:about', or add{{ space }}ARGS=--interactive{{ space }}to open the interactive picker.

3. Choose a web mode

Run these commands from the Serenade repository root. HTML and Universal run a local server; SPA and SSG create static build output.

SERVER · HTML

A server-rendered app

Run{{ space }} MyFeed, the fuller HTML example, on your machine. 

make html

Open http://127.0.0.1:8080/. The process stays running until you stop it.

BUILD · SPA

A client-rendered app

Build the Leptos SPA and its interactive counter with Trunk.

{{ spaCommands }}

Open http://127.0.0.1:4173/. The build output is examples/demo-monorepo/apps/demo-spa/dist/.

BUILD · SSG

Prerendered pages, hydrated

Build static HTML for the home and about routes, plus the browser hydration bundle. 

{{ ssgCommands }}

Open http://127.0.0.1:4173/ or http://127.0.0.1:4173/about/. Generated files are in examples/demo-monorepo/apps/demo-ssg/dist/.

SERVER · UNIVERSAL

A frontend with a live backend

Build the frontend, then run the backend that serves assets, JSON, and a server-rendered page. 

make universal

Open http://127.0.0.1:8080/ and http://127.0.0.1:8080/cms/hello. Stop the process when finished.

One local server at a time

HTML and Universal both use 127.0.0.1:8080 by default. Stop one before starting the other. The SPA and SSG examples share a port only when you serve their generated files; stop that preview server before reusing port 4173.

4. Keep exploring

Use{{ space }}make html-all,{{ space }}make spa-all,{{ space }}and{{ space }}make ssg-all{{ space }}to select every registered app in those modes. Each command currently has one demo app. Read the example guides for details and environment settings.

Browse all examples Read the front modes guide Core bundle demo

5. Choose your building blocks

Start with the components your product needs. Select an HTTP adapter and persistence strategy deliberately; Serenade does not require one server or ORM.

Pre-1.0 project

Crates evolve independently and APIs can change. Check each crate's README, tests, and current API documentation before adopting it.
